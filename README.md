## Overview
Frontend User Interface (UI) implementation for the **FoodRank Islamabad** mobile application built with Flutter. This repository contains only the UI layouts, navigation flows, reusable widgets, and custom styling (no backend code).

## Included Screens & Components
- **Welcome & Authentication (`welcome_screen.dart`, `auth_screens.dart`):** Onboarding flow, login, and signup screens.
- **Home & Discovery (`home_screen.dart`, `home_screens.dart`, `discovery_screens.dart`):** Ranked food listings, category filters, and search interface.
- **Dish Details (`dish_detail_screen.dart`):** Detailed dish view with ratings and restaurant information.
- **Reusable Widgets (`common_widgets.dart`, `dish_rank_card.dart`):** Custom cards, buttons, and layout components.
